# Generated assets

The following assets are generated by Flutter golden tests and committed to the repo:

- `screenshots/checklist_main.png` — README screenshot
- `frames/f*.png` + `docs/app_demo.mp4` — demo video frames

These tests were removed from the suite because golden tests without a
committed baseline report a failure on first run. To regenerate:

    flutter test --update-goldens test/video_frames_test.dart   (frames)
    flutter test --update-goldens test/screenshot_test.dart     (screenshot)

(The test sources were removed; see git history for the test code.)
